# 使用方法

## 编译

在项目根目录运行命令：

```
mvn clean package -P get-jar-with-dependencies
```

得到编译产物jar包。

## 准备

将jar包移动至IoTDB目录`ext/udf`下。

## 运行

进入IoTDB客户端界面，使用如下命令注册UDF：

```
create function matrix as 'org.apache.iotdb.udf.UDTFMatrixProfile'
create function matrix_anomaly as 'org.apache.iotdb.udf.UDTFMatrixProfileAnomaly'
```

运行如下命令即可调用：

```
SELECT {column_name}, matrix({column_name}, "k"="{k}", "window"="{window}") FROM {time_series_name}
SELECT {column_name}, matrix_anomaly({column_name}, "k"="{k}", "window"="{window}", "percentile"="{percentile}") FROM {time_series_name}
```

其中：

- `column_name`：计算Matrix Profile的列名
- `k`：不计算Matrix Profile的临近位置个数
- `window`：Matrix Profile的子序列长度
- `percentile`：Matrix Profile高于多少比例的位置则视为异常（单位：%）
